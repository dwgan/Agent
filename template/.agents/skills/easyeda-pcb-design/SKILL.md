# 嘉立创EDA PCB 设计入口

## 目标

把当前 Codex 会话接入已经打开的嘉立创EDA工程，并在可回退、可核查的前提下完成设计工作。具体 EDA API 操作必须同时使用官方 `easyeda-api` Skill；本 Skill 只规定入口流程、工程安全边界和交付标准，不复制官方 API 文档。

## 启动

用户明确调用本 Skill 后：

1. 告诉用户正在连接嘉立创EDA，并说明当前阶段只做连接和只读盘点。
2. 读取并遵守官方 `easyeda-api` Skill；每次调用 EDA API 前按其要求核对完整签名、参数、枚举、单位和返回值，不猜测接口。
3. 扫描 `127.0.0.1:49620-49629`，只接受 `/health` 中 `service` 为 `easyeda-bridge` 的服务。
4. 没有 Bridge 时，使用同仓库的 `easyeda-environment-setup` 启动或排障，不重复安装已存在的环境。
5. 没有连接窗口时，让用户打开嘉立创EDA并确认 Run API Gateway 已加载；不要使用坐标点击脚本代替官方入口。
6. 多个窗口连接时列出窗口并让用户选择；只有一个窗口时直接使用。
7. 通过只读 API 获取当前工程、当前文档、板子/图页列表和必要的设计摘要，然后报告实际识别结果。

用户以后可以直接发送：

```text
$easyeda-pcb-design 连接我当前打开的嘉立创EDA工程，先只读检查，然后帮我完成……
```

## 开始设计前

从用户描述和当前工程中建立以下信息；能从工程可靠读取的内容不要重复询问：

- 目标功能、供电、接口、关键器件和板框/安装限制。
- 层数、铜厚、阻抗、电流、温升、安规、EMC、成本和装配约束。
- 哪些文档允许修改，哪些原理图、PCB、封装或网络必须保持不变。
- 当前阶段是只读审查、局部修改、完整设计、拼板还是生产检查。
- 阶段验收条件，以及最终仍需工程师实测或人工确认的项目。

若缺失信息会改变电气安全、封装选择、板框、层叠或生产结果，先停在设计确认点；普通布局偏好等低风险细节可采用明确说明的合理假设继续。

## 执行原则

- 默认先读后写。用户只要求检查、解释或诊断时，不修改和保存工程。
- 用户授权设计或修改后，只操作明确范围内的文档；不要顺手改动原始板、其它工程或库文件。
- 大范围变更前优先复制目标 PCB/原理图或建立其它可回退检查点，并清楚命名。
- 原理图、封装、PCB、拼板分阶段完成；每阶段先核对对象数量、网络和关键几何，再进入下一阶段。
- 使用 PCB 单位 `1 mil`、原理图单位 `10 mil`；转换后回读坐标或尺寸验证。
- 修改图元使用官方异步图元模式；修改覆铜边界后重建覆铜并检查返回值。
- `setDocumentSource` 仅在公开 API 无法表达操作、格式文档明确且目标可回退时使用。返回 `false` 时立即停止，不把失败写回当作成功。
- 不调用未记录的内部接口，不猜枚举或参数，不把 GUI 焦点变化当作设计成功。
- 嘉立创EDA API 无法安全完成的 GUI 操作，只请求用户完成最少的必要动作，随后继续自动核查。

## 硬件与生产边界

- AI 的设计和 DRC 不能替代器件数据手册复核、原理图评审、样板上电、示波器/逻辑分析仪测量、热测试、EMC/安规测试和工厂工程确认。
- 电源、功率、电机驱动、电池、高压、隔离、急停和保护相关设计必须显式列出未验证风险。
- 不因方便而缩小安全间距、线宽、过孔、阻焊桥或板边距离；需要例外时说明规则来源并等待用户确认。
- 拼板需检查板间距、铣槽/V-CUT适用性、工艺边、定位孔、全局 Mark、邮票孔、器件到分板边距离和 SMT 厂能力。
- 混拼、特殊板框或工艺参数应在下单前让板厂确认；不要声称“可直接量产”，除非所有自动检查和人工确认均已完成。

## 验证与交付

每个写入阶段完成后：

1. 回读当前工程和文档 UUID，确认没有写错对象。
2. 回读关键图元数量、网络、板框、坐标、层和尺寸；不能只依据写入 API 的成功返回值。
3. 对覆铜执行重建，对适用的 PCB 执行 DRC，并按类别汇总错误数量和关键位置。
4. 保存目标文档并检查保存返回值。
5. 向用户报告：完成内容、实际修改对象、验证结果、仍存在的 DRC/制造风险、需要人工完成的下一项检查。

只有在目标修改已经回读确认、保存成功且没有隐瞒未解决问题时，才报告当前阶段完成。
